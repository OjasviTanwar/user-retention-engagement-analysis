# User Retention & Engagement Analysis

Analysis of user engagement and churn drivers across ~3,000 users, visualized in an interactive Power BI dashboard.

## Scope

- **Users:** ~3,000
- **Period:** January – March 2025
- **Product categories:** Beauty, Fashion, Home, Sports, Electronics
- **Countries:** USA, Canada, India, UK, Germany
- **Device mix:** Mobile ~35%, Desktop ~33%, Tablet ~32%

## What's Inside

| File | Description |
|------|-------------|
| `user_retention_engagement_data.pbix.pdf` | Full Power BI dashboard export — KPI cards, category/country/device breakdowns, engagement trends, and segment comparisons |

## Key Findings

- Device usage is nearly evenly split across mobile, desktop, and tablet — retention strategies must be device-agnostic
- Engagement varies meaningfully by product category and country, pointing to localized re-engagement opportunities
- Analysis combined ETL, data cleaning, outlier removal, cohort segmentation, and correlation analysis

## Tech Stack

Python (Pandas, NumPy, Matplotlib, Seaborn) · Power BI · Excel
